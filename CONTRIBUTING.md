# Contributing to nvim-config

## Setting Up Your Development Environment

### Prerequisites

Ensure you have the following installed:

- [NVim](https://neovim.io/doc/install)
- [Jujutsu](https://docs.jj-vcs.dev/latest/install-and-setup)

### Clone the Repository

```sh
git clone https://github.com/jolafrite/nvim-config.git
cd nvim-config/
```

### Use the config

```sh
nvim -u ./init.lua
```
