- **Last Update** = the commit date of the pinned revision in `nvim-pack-lock.json`. All 114 plugins are pinned to specific commits (not floating branches).

- **Redundant** marks plugins that are functionally superseded by another installed plugin:
  - `mini.diff`, `mini.files`, `mini.operators`, `mini.pairs`, `mini.surround`, `mini.visits` — submodules of `mini.nvim`, pinned separately in the lockfile but configured through `mini.nvim`.

- **Removed** (spec files deleted and lockfile pins dropped on 2026-09-02):
  - `nvim-autopairs` — redundant with `mini.pairs` / `blink.pairs`.
  - `nvim-surround` — redundant with `mini.surround`.
  - `nvim-web-devicons` — mocked by `mini.icons` via `package.preload` in `lua/plugins/mini.lua`; `lualine.lua` uses inline icons and never loads it.
  - `ultimate-autopair.nvim` — spec file was 0 bytes and never referenced.

- **Unreferenced toolchain repos** — pinned and installed, but no `lua/` file references them (these tools are installed via Mason instead): `clangd`, `gleam`, `nushell`, `biome`, `setup-dart`, `tailwindcss-intellisense`, `vuejs/language-tools`. Candidates for removal from the lockfile.
- All 114 repos are on GitHub; descriptions shown as `—` have none set in this document (the upstream metadata fetch mostly failed — links above come from the lockfile and are authoritative).
